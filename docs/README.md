# Dokumentation: Brüche von Anfang an

## Projektüberblick

Interaktive Lernseite zum Thema Brüche. Ziel ist eine verständliche, browserbasierte Unterstützung beim Lernen und Üben.

## Architektur und Dateiaufbau

- `index.html` – Einstiegspunkt der Lernseite; Inhalte, Gestaltung und Verhalten sind dort beziehungsweise in den dazugehörigen Projektdateien zu finden.

## Entwicklung und Prüfung

1. `index.html` in einem aktuellen Browser öffnen.
2. Geänderte Lerninhalte und Interaktionen im Browser durchspielen.
3. Darstellung und Bedienbarkeit auch bei schmalem Bildschirm prüfen.
4. Im Pull Request oder Commit kurz festhalten, was geändert und geprüft wurde.

## Pflege und offene Aufgaben

Bei neuen Aufgaben den GitHub-Issue-Tracker verwenden und Ziel, erwartetes Verhalten sowie Prüfschritte angeben.

### Pflege-Checkliste

- [ ] Lernziel und fachliche Richtigkeit prüfen
- [ ] Aufgabenstellung und Rückmeldungen verständlich formulieren
- [ ] Bedienbarkeit per Tastatur und auf Mobilgeräten prüfen
- [ ] Änderungen im Browser getestet
- [ ] README und diese Dokumentation bei Änderungen aktualisieren
